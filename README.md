# XA Hardware Lab

Android hardware testing app for Sony Xperia SO-05K and other Android 8+ devices.

Features: battery status and temperature, CPU info where available, accelerometer, sensor inventory, flashlight and vibration tests.

No root required.

## Build

GitHub Actions -> Build XA Hardware Lab APK -> Run workflow. After success, download the XA-Hardware-Lab-APK artifact ZIP, extract the APK, and install it.

The APK is a debug build for personal testing, not a Play Store release.
